## Feature Graphic (Gráfico de Funciones)

**Tamaño requerido**: 1024 x 500 px
**Formato**: PNG o JPEG

### Cómo generarlo:

1. Abre el archivo `feature_graphic/generator.html` en tu navegador
2. Haz clic en "Descargar PNG"
3. El archivo se guardará con las dimensiones correctas

### Ubicación:
- `feature_graphic/feature_graphic.png` (generar desde HTML)
